# Activate agents

Use `wizengamot --workspace <path> activate --domain <slug> --role <slug>` or `--name <agent-name>`. Activation copies selected definitions into the workspace's `.claude/agents/activated/` directory. Clear the directory before switching investigations. Use batch execution for large rosters.
